Six things it does.

See which agent needs you

Claude Code, Codex, OpenCode, Pi and Cursor report through hooks, any zsh command through the shell. The border says working, waiting on you, failed or done.

ift install-claude-hooks

A canvas, not tabs

Zoom out to see every card, zoom in to work in one. A new card takes the next free slot, and nothing moves on its own.

Cmd 2 fits every card

Shells that outlive the app

Each shell runs in its own small daemon. Quit or update the app and the programs keep running; reopen it and the screen comes back as it was.

ssh -t mac ift attach 7

Driven from any shell

ift opens files over the card you are in, lists cards, types into another card and reads what it shows.

ift send 7 "npm test" --enter

Servers in their own window

A second window whose cards run on a Linux server or another Mac over ssh. Close it and the shells stay on the server.

ift connect me@server

The rest of the work beside it

Editor, diff, transcript and browser cards on the same canvas: the files, the changes against HEAD, a session's turns, and Chromium.

ift diff

Every feature →

Four colours, because there are four questions.

Claude Code, Codex, OpenCode and Pi report through hooks. Any other command reports through zsh, so a long build goes violet and then green, and a failing one goes red. A shell doing nothing has no colour at all.

Nothing flashes. Nothing steals focus.

There are no notifications and no bouncing icons. You look when you are ready, see which cards changed colour, and go there. Other workspaces tell you from their tab: one dot per card, in the order the cards sit, lit in that card's colour.

Cmd is the app's. Everything else is your shell's.

Ctrl, Alt and bare keys go to the terminal untouched, so vim, tmux and your readline habits keep working. Every action is a command, so nothing needs the mouse.

All keys

  • Cmd T new card, placed where you can predict
  • Cmd Alt ← the card to the left
  • Ctrl Tab the cards you worked in, most recent first
  • Cmd 2 fit every card in the window
  • Cmd Shift P every command, by name

What it does not have.

No Electron. No account. No telemetry.

A native app in Rust. The only request it makes on its own is the update check, a plain GET with nothing about you in it. Everything it touches is written down.
