# Repo map: assets, site, tools, docs

What this covers: the part of the file map that is not a Rust crate: `assets/`, `site/`, the build, signing, release and driver scripts under `tools/`, `HANDOVER.md`, `docs/` and `spikes/`.

Read it before touching `site/`, `tools/`, `assets/`, the Makefile's bundle and release targets, or when you need to find which script does a thing. The crate map (`infiniterm-core/`, `-term/`, `-editor/`, `-browser/`, `-ui/`, `-cli/`) stays in CLAUDE.md.

Related: `release-and-site.md` (how a release and the site deploy work), `traps-workflow.md` (bundle, signing and driver traps).

Moved here from CLAUDE.md on 2026-10-19 with the text unchanged.

```
assets/                     the app icon (Tarık Kavaz's four-card icon, 0.5.0) and themes/ (the README's screenshot is `site/public/canvas.png`): the 522 iTerm2-Color-Schemes files (MIT, licence inside) the bundle ships; bundle.sh stops when the folder is missing (it copied them from the archived Tauri checkout before, and a Mac without it built a bundle with NO themes, silently)
site/                       infiniterm.app: Astro + Starlight. src/pages/index.astro is the landing page (its own design, not Starlight), src/content/docs/guide/*.md the hand-written guide, reference/{keys,commands,settings}.md GENERATED and gitignored (only those three: `ift`'s verbs and flags reach the site by hand, in guide/ift-and-sessions.md) (`npm run reference` runs `cargo run -p infiniterm-core --example site_reference`; `dev` and `build` run it first), public/ holds install.sh, film.html (typereel's launch film, recopied from ~/Code/typereel/films/infiniterm/scene.html when it changes; its poster is film-poster.png, the film's opening frame, recapture it with the film), canvas.png (the home page screenshot, retaken with tools/drive/hero-shot.sh), icons, og.png, CNAME. src/layouts/Landing.astro is the head, top bar, footer and styles both landing-style pages share (index.astro, features.astro); src/data/features.ts is the one feature list, rendered as /features and as reference/features.mdx (hand-written, not generated), kept by hand against the CHANGELOG at each release. `site/deploy.sh` builds and force-pushes dist/ as one orphan commit to the main repo's gh-pages branch, which Pages serves at infiniterm.app (DNS on Cloudflare, managed with the `cf` CLI). The site is deployed only when a release is published (Ekin, 2026-10-05), so it never documents what users cannot download; a landing-page change wanted sooner is deployed from the release tag with only that change cherry-picked on it. starlight-llms-txt writes /llms.txt, /llms-full.txt, /llms-small.txt from the same pages
tools/bundle.sh             target/bundle/infiniterm.app: cef-rs's bundle-cef-app plus themes, icon, ift, iftd and the hook as sidecars
tools/sign.sh, entitlements.plist   Developer ID signing of the bundle (every `make bundle`); bundle.sh stamps the version (workspace) and build (commit count)
tools/dist.sh, publish.sh   `make dist`: the build that leaves this Mac, a notarized, stapled DMG + update zip + latest.json in target/dist, checked with spctl as a friend's Mac would; `make publish` puts it on the main repo's releases and then runs tools/bump-cask.sh, which rewrites the version and sha256 of Casks/infiniterm.rb in the public ekinertac/homebrew-tap (tools/test-bump-cask.sh, DRY_RUN)
tools/drive/hero-shot.sh    the landing page's screenshot scene on a clean scratch instance (HERO_DIR, its own ZDOTDIR with a neutral .zshrc so the user's prompt and fetch banner stay out): cards made with `ift run card.new.terminal`, filled with `ift send`, states from the hook binary; started and stopped by its own pid. The 2026-10-06 shot used real agent sessions in a demo repo under /Users/Shared/acme (no username in paths)
tools/test-install.sh       runs site/public/install.sh (the curl | sh installer: latest.json's zip, sha256, codesign against the team, spctl, /Applications, `ift install`, agent hooks only when asked or `--hooks`) against a scratch HOME and Applications folder and the real latest release
tools/usage-stats.py        active Macs estimated from GitHub's download count of the newest release's latest.json (24 fetches a Mac a day at the hourly check, 4 for builds before 0.5.14); the launch plan's measure, since the app has no telemetry (docs/marketing-plan.md)
tools/drive/                the GUI driver: lib.sh, then one scenario per area (terminal, select, editor, diff, transcript, browser, stress, idle, settings, ift, multicursor, editor-overflow, complete ...). cast.sh is the odd one out: not a test but the screencast take, paced for a camera, on its own demo repo and canvas under /tmp/infiniterm-cast (`make cast-seed` once, then `make cast`)
tools/locked.swift, winid.swift   the driver's probes: is the Mac locked, which window belongs to which pid
tools/paintlog.sh           relaunches the installed app with `[paint]` logging into ~/infiniterm.log (quit it first); how the far-zoom numbers were measured
HANDOVER.md                 the rewrite's log, phase by phase, with the measurements and decisions
docs/                       roadmap.md (where this stands: done, v1.5, v2, parked; the file to update when something ships); the file-by-file map from the Tauri app, kept as history; tmux-handover.md (the tmux backend's checkpoint, bugs and open items); superpowers/ (the omnibox and daemon specs and plans)
spikes/*/NOTES.md           the four spikes' measurements; their code is gone (git log has it). cef-extension/profile (gitignored) seeds the browser profile once
```
